# Example: Seller SMS

## Strong Copy

```text
Hi [first_name], this is [agent_name] with [brokerage]. Is selling in [market]
this year even on the radar, or should I leave this alone? Reply STOP to opt
out.
```

Follow-up:

```text
I can send a realistic value/timing check without a listing pitch. Useful, or
not relevant? Reply STOP to opt out.
```

## Bad Copy

```text
Your home value is exploding. I can sell it fast for maximum money.
```

## Why Bad Copy Fails

- Unsupported value claim.
- Implies guaranteed speed and price.
- Sounds automated and high-pressure.

## Improved Rewrite

```text
I can put together a practical value range and selling timeline for [market].
Want the short version? Reply STOP to opt out.
```

## Compliance Notes

Do not imply knowledge of sensitive owner circumstances. Do not guarantee value,
speed, or buyer availability.
