# Example: Reactivation

## Strong Copy

```text
Hi [first_name], [agent_name] with [brokerage]. We connected before about
[buying/selling] in [market]. Is that still active, paused, or solved?
```

Follow-up:

```text
If it is active again, I can refresh the plan instead of starting from scratch.
If it is solved, I will close the loop.
```

## Bad Copy

```text
You never got back to me. Are you ready to move forward now?
```

## Why Bad Copy Fails

- Guilt-based.
- Sounds irritated.
- Assumes the lead owes a response.

## Improved Rewrite

```text
I am cleaning up old conversations. Should I mark this active, paused, solved,
or not relevant?
```

## Compliance Notes

Use only when prior relationship/source is documented and follow-up is allowed.
Include opt-out for SMS where required.
