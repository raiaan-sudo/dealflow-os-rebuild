# Example: Seller Cold Call

## Strong Copy

```text
Hi [first_name], this is [agent_name] with [brokerage]. I might be early here,
so tell me if I am off. Are you considering selling the [market] property this
year, or is it a firm hold?
```

If open:

```text
The useful first step is not a listing pitch. It is a realistic value range and
timeline so you know what would need to be true.
```

Close:

```text
Would a 10-minute value and timing check be useful this week?
```

## Bad Copy

```text
I have buyers waiting for your home and can get you top dollar guaranteed.
```

## Why Bad Copy Fails

- Fake buyer implication unless a real approved match exists.
- Guaranteed outcome.
- High distrust if the homeowner asks for proof.

## Improved Rewrite

```text
I can check current buyer demand for homes like yours and give you a practical
value range. If selling is not on the radar, no problem.
```

## Compliance Notes

Do not promise buyer demand, sale price, or outcomes. Avoid pressure on owners
who clearly do not want to sell.
