# Example: Expired Listing

## Strong Copy

```text
Hi [first_name], this is [agent_name] with [brokerage]. I know you probably got
too many calls after the listing came off. I will be brief. Are you still open
to selling if the plan is better, or are you done for now?
```

## Bad Copy

```text
Your last agent failed. I can relist it and get it sold.
```

## Why Bad Copy Fails

- Disparages another professional.
- Guarantees a sale.
- Creates defensiveness.

## Improved Rewrite

```text
Expired listings usually stall because of some mix of pricing, presentation,
buyer targeting, and follow-up. I can do a short recovery review if you still
want to sell.
```

## Compliance Notes

Respect representation status. Do not contact if the seller has relisted or is
represented unless legally and ethically approved.
