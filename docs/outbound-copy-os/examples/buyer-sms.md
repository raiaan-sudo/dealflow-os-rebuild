# Example: Buyer SMS

## Strong Copy

```text
Hi [first_name], this is [agent_name] with [brokerage]. Are you still looking
around [market], or did that pause? Reply STOP to opt out.
```

Follow-up:

```text
If useful, I can send a short list matched to [area] and [budget]. Want it, or
not relevant right now? Reply STOP to opt out.
```

## Bad Copy

```text
HOT DEALS in [market]!!! Click now before these homes disappear.
```

## Why Bad Copy Fails

- Spammy tone.
- Fake urgency.
- No sender identity.
- No opt-out.

## Improved Rewrite

```text
[agent_name] with [brokerage] here. Want a short [market] list that fits your
budget and timing? Reply STOP to opt out.
```

## Compliance Notes

SMS requires source/consent review. Include opt-out where required and never use
links in early cold touches unless approved.
