# Audience Offer Map

Use this map before generating copy. The offer must fit the audience, pain
point, consent posture, and channel. Bad-fit offers create complaints and weak
appointments.

## Selection Rules

- If the audience is uncertain, choose a low-risk diagnostic offer rather than a
  strong appointment ask.
- If consent/source status is weak, draft for internal review only.
- If the offer needs proof, name only approved proof.
- If the offer could imply discrimination, rewrite around property criteria,
  timing, budget, and preferences controlled by the lead.
